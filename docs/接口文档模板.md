## 一、接口名称 (例如：分页查询商品列表)

### 1. 基础信息
* **接口路径**：`/api/v1/resource/path`
* **请求方法**：`GET` / `POST` / `PUT` / `DELETE`
* **接口版本**：`v1.0`
* **Content-Type**：`application/json` （或 `application/x-www-form-urlencoded` / `multipart/form-data`）

---

### 2. 请求参数

#### 2.1 Header 参数
| 序号 | 参数名        | 类型   | 必填 | 示例               | 说明           |
| ---- | :------------ | :----- | :--- | :----------------- | :------------- |
| 1    | Authorization | String | 是   | Bearer eyJhbGci... | 用户鉴权 Token |
| 2    | Trace-Id      | String | 否   | 5b2c4c...          | 链路追踪 ID    |

#### 2.2 Path 路径参数
| 序号 | 参数名 | 类型 | 必填 | 示例  | 说明            |
| ---- | :----- | :--- | :--- | :---- | :-------------- |
| 1    | id     | Long | 是   | 10086 | 资源唯一标识 ID |

#### 2.3 Query 查询参数
| 序号 | 参数名  | 类型    | 必填 | 默认值 | 示例 | 说明         |
| ---- | :------ | :------ | :--- | :----- | :--- | :----------- |
| 1    | page    | Integer | 否   | 1      | 1    | 当前页码     |
| 2    | size    | Integer | 否   | 10     | 10   | 每页显示条数 |
| 3    | keyword | String  | 否   | -      | 手机 | 搜索关键字   |

#### 2.4 Body 请求体 (JSON)
| 序号 | 参数名   | 类型          | 必填 | 示例           | 说明                 |
| ---- | :------- | :------------ | :--- | :------------- | :------------------- |
| 1    | username | String        | 是   | zhangsan       | 用户名，长度 2-20 位 |
| 2    | age      | Integer       | 否   | 18             | 年龄                 |
| 3    | tags     | Array[String] | 否   | ["IT", "Java"] | 用户标签列表         |

---

### 3. 响应定义

#### 3.1 响应结构
| 序号 | 参数名  | 类型           | 说明                                  |
| ---- | :------ | :------------- | :------------------------------------ |
| 1    | code    | Integer        | 状态码：200 表示成功，非 200 表示失败 |
| 2    | message | String         | 提示信息                              |
| 3    | data    | Object / Array | 业务响应核心数据                      |

#### 3.2 业务数据字段 (`data`) 说明
| 序号 | 参数名 | 类型    | 说明                         |
| ---- | :----- | :------ | :--------------------------- |
| 1    | total  | Long    | 总记录数 (分页查询时使用)    |
| 2    | list   | Array   | 数据对象列表                 |
| 2.1  | id     | Long    | 数据 ID                      |
| 2.2  | status | Integer | 状态：0-禁用，1-启用，2-锁定 |

---

### 4. 报文示例

#### 4.1 请求示例 (cURL / JSON)
```json
{
  "username": "zhangsan",
  "age": 18,
  "tags": ["IT", "Java"]
}
```

#### 4.2 成功响应示例 (`200 OK`)

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "total": 100,
    "list": [
      {
        "id": 1,
        "status": 1
      }
    ]
  }
}
```

#### 4.3 异常响应示例 (`400 Bad Request`)

```json
{
  "code": 40001,
  "message": "用户名已存在",
  "data": null
}
```
